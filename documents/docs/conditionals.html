Conditionals & Loops

Control what's in the DOM. ly-if inserts or omits content, and ly-for renders lists — both driven by <template> elements.

ly-if / ly-else-if / ly-else

Wrap branches in <template> elements. Only the first matching branch is inserted into the DOM.

<template ly-if="loggedIn">
    <div>Welcome back, <span ly-text="username"></span>!</div>
</template>
<template ly-else-if="loading">
    <div>Authenticating…</div>
</template>
<template ly-else>
    <div>Please log in to continue.</div>
</template>

ly-show keeps the element in the DOM and only hides it; ly-if actually removes it. Prefer ly-if for heavy or rarely-needed branches.

ly-for — iterate lists

Iterate arrays with a <template ly-for>. Destructure the item and optional index, then access both inside the template.

<ul>
    <template ly-for="item in items">
        <li ly-text="item"></li>
    </template>
</ul>

<!-- With index -->
<template ly-for="(item, index) in items">
    <div>
        <span ly-text="index + 1"></span>: <span ly-text="item.name"></span>
    </div>
</template>

ly-key — stable identity

For mutable lists, give each rendered item a stable identity with ly-key. Lyap uses it to keep items stable across re-renders.

<template ly-for="(item, index) in items">
    <div ly-key="item.id">
        <span ly-text="item.name"></span>
    </div>
</template>

Numbers and objects

ly-for can also iterate a number (producing 1..n) or an object (producing { key, val } entries).

<!-- Number range: renders 1, 2, 3 -->
<template ly-for="n in 3">
    <span ly-text="n"></span>
</template>

<!-- Object entries -->
<template ly-for="entry in config">
    <p><span ly-text="entry.key"></span>: <span ly-text="entry.val"></span></p>
</template>

Array mutations are reactive. Pushing, popping or splicing the array bound to ly-for re-renders the list automatically.
