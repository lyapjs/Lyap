LyapJs Documentation

HTML-First Reactive Micro-Framework for Modern Web Applications.

Zero Build Step
Include a 22 KB CDN script tag and start writing reactive HTML components immediately without complex build toolchains.
100% CSP Compliant
Employs a safe sandboxed AST token evaluator — zero reliance on unsafe eval() or new Function().
Signal-Based Reactivity
Fine-grained reactive signals track target property dependencies for surgical DOM updates without Virtual DOM overhead.
Scoped HTML State
Declare reactive state inside standard <script type="lyap"> tags with prototypal DOM scope inheritance.

Basic Example

Declare state inside a script tag and bind properties using declarative directives:

<!-- Load LyapJs Production CDN -->
<script src="https://unpkg.com/@lyapjs/dom"></script>

<!-- Reactive HTML Component -->
<div>
  <script type="lyap">
    state({ count: 0 });
  </script>

  <button ly-on:click="count++">Increment</button>
  <span ly-text="count"></span>
</div>
