Core Architecture

An overview of the architectural design principles powering LyapJs.

1. Prototypal Scope Delegation

Scopes inherit hierarchically down the DOM element tree using standard JavaScript prototypal inheritance:

child scope
  ↓ (inherits from)
parent scope
  ↓ (inherits from)
root scope

2. CSP-Compliant Lexical Micro-Evaluator

LyapJs implements a custom lexer and AST token evaluator. Expressions like ly-text="a + b" parse without dynamic code evaluation APIs (eval, new Function), ensuring full compatibility with restrictive Content Security Policies.

3. Fine-Grained Signal Stores

State properties declared in state({ ... }) are backed by Proxy stores. Reading properties during DOM walking automatically registers active observer dependencies for targeted DOM mutations.

4. Batched Microtask Scheduler

Synchronous state mutations coalesce using queueMicrotask into single atomic update passes, optimizing rendering pipeline overhead.
