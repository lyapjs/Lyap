Getting Started

Lyap adds reactivity to plain HTML. Drop in one script tag, write a little markup, and you're done.

Installation

Download lyap.min.js and include it before the closing </body> tag of your page. Lyap automatically boots and scans your markup on DOMContentLoaded.

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My Page</title>
</head>
<body>

    <!-- Your markup + lyap scripts go here -->

    <script src="lyap.min.js"></script>
</body>
</html>

You can also load it from a CDN or any static host:

<script src="https://example.com/lyap.min.js"></script>

Your first reactive page

A Lyap app is just HTML. State and logic are declared inside a <script type="lyap"> block, and directives bind it to the markup around it.

Live previewlyap

Count: 

<div>
    <script type="lyap">
        state({ count: 0 });

        function increment() {
            count++;
        }
    </script>

    <p>Count: <span ly-text="count"></span></p>
    <button ly-on:click="increment">Increment</button>
</div>

How it works: the <script type="lyap"> block binds to its nearest parent container. Browsers ignore it natively, so it's invisible until Lyap boots.

Core ideas

Before continuing, it helps to understand the three pieces of every Lyap scope:

  • State — declared with state({...}). Reassigning a state property updates anything bound to it.
  • Derived values — declared with derived({...}). Read-only values computed from state, automatically kept in sync.
  • Directives — attributes like ly-text, ly-on, ly-show and ly-for that declare the reactive behavior in HTML.

Tip: wrap containers that read from state on load with ly-cloak to avoid a flash of unstyled content. See Text, Show & Cloak.
