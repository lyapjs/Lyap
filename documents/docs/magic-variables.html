Magic Variables (`$*`)

Built-in context helper variables available in directives, event handlers, and script functions.

1. `$event` (DOM Event)

Access the underlying native DOM Event object inside ly-on:* event handlers.

<input ly-on:input=":query = $event.target.value" />

2. `$el` (Element Reference)

Direct reference to the active target HTMLElement.

<button ly-on:click=":$el.classList.toggle('active')">Toggle</button>

3. `$refs` (Named Element Map)

Access elements tagged with ly-ref="name" directly via $refs.name.

<input ly-ref="searchInput" />
<button ly-on:click=":$refs.searchInput.focus()">Focus</button>

4. `$form` (Form Assistant Context)

Form Assistant context available inside <form> elements:

$form.data      // Snapshot object of form values
$form.reset()   // Resets form controls & scope state
$form.isDirty   // true if any control has been modified
$form.isValid   // true if HTML5 validation passes

5. `$nextTick` (Async DOM Flush)

Returns a Promise that resolves after LyapJs finishes flushing pending reactive state updates to the DOM.
