Script State Tags (`<script type="lyap">`)

Declare state properties, derived values, actions, and lifecycle hooks inside HTML script tags.

1. State Declaration (`state()`)

Initializes reactive properties wrapped in store proxies:

<script type="lyap">
  state({
    count: 0,
    user: { name: 'Ada' }
  });
</script>

2. Derived Computed State (`derived()`)

Declares memoized read-only computed values that update when dependencies change:

<script type="lyap">
  state({ count: 10 });

  derived({
    doubleCount() {
      return count * 2;
    }
  });
</script>

3. Component Lifecycle Hooks

LyapJs provides 4 lifecycle hooks to manage scope lifecycle events:

init(() => { ... })
Executed during initial scope creation before directive walking.
mount(() => { ... })
Executed immediately after element & scope attach to the DOM.
cleanup(() => { ... })
Registered inside mount() to clean up timers and listeners.
destroy(() => { ... })
Executed when the container element and scope are destroyed.
