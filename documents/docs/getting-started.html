Quick Start Guide

Instructions for integrating LyapJs into existing web applications or new projects.

1. CDN Installation

Include the production bundle via script tag inside your document <head> or at the bottom of the body:

<!-- CDN Installation -->
<script src="https://unpkg.com/@lyapjs/dom"></script>

2. Package Installation

Install the modular packages via package manager for bundled environments:

npm install @lyapjs/dom @lyapjs/reactive

3. Preventing FOUC (`ly-cloak`)

To prevent Flash of Uncompiled Content during initialization, apply the ly-cloak attribute along with the CSS declaration:

<style>
  [ly-cloak] { display: none !important; }
</style>

<div ly-cloak>
  <script type="lyap">
    state({ message: 'Ready' });
  </script>
  <span ly-text="message"></span>
</div>
