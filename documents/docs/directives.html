Directives Reference

Complete API specification for all declarative ly-* HTML binding directives.

1. `ly-text`

Sets element textContent securely to avoid XSS injections.

<span ly-text="userName"></span>

2. `ly-bind`

Two-way data binding for input elements. Supports .trim and .number modifiers.

<input type="text" ly-bind.trim="email" />

3. `ly-class`

Dynamically applies or removes CSS classes based on condition tokens prefixed with :.

<button class="btn" ly-class=":isActive active :isDisabled disabled">Submit</button>

4. `ly-show`

Toggles CSS display: none visibility state without modifying DOM element structure.

<div ly-show="isVisible">Panel Content</div>

5. `ly-attr:*`

Binds any standard HTML element attribute dynamically.

<button ly-attr:disabled="!isFormValid">Submit</button>

6. `ly-for`

Iterates collections using <template ly-for="item in items"> blocks.

<template ly-for="item in items">
  <div ly-text="item.name"></div>
</template>

7. `ly-if` / `ly-else`

Conditionally mounts or unmounts DOM nodes based on evaluated expression truthiness.

<template ly-if="isLoggedIn">
  <div>User Dashboard</div>
</template>
<template ly-else>
  <div>Login Required</div>
</template>

8. `ly-on:*`

Attaches event listeners with modifiers (.outside, .prevent, .self, .stop, .once).

<button ly-on:click="submit">Submit</button>
<button ly-on:click=":count++">Increment</button>
