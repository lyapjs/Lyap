Magic Variables

Lyap injects a set of context-aware variables into event handlers, inline expressions and script functions. They're always available — no imports, no setup.

$event — the native DOM event

Available inside ly-on:* handlers.

UsageDescription
$event.targetThe element that triggered the event.
$event.target.valueCurrent value of an input element.
$event.key / $event.codeKeyboard key details.
$event.preventDefault()Stops default browser behavior.
$event.stopPropagation()Stops the event bubbling.
 
<input ly-on:input=":search = $event.target.value">
<input ly-on:keyup=":pressed = $event.key">

$el — current element

Available in any directive or script callback — a direct reference to the element itself.

<button ly-on:click=":$el.blur()">Blur me</button>
<div ly-on:click=":$el.classList.add('selected')">Click me</div>

$refs — named element map

Available across the entire container scope. Tag any element with ly-ref="name" and access it via $refs.name.

Live previewlyap
<input ly-ref="searchInput">
<button ly-on:click=":$refs.searchInput.focus()">Focus</button>

$scope — container state proxy

Available in action functions and callbacks. Direct access to the container's reactive state — handy for logging snapshots or passing state to utilities.

<script type="lyap">
    function debugState() {
        console.log($scope.count);
    }
</script>
<button ly-on:click="debugState">Log state</button>

$form — form assistant

Available inside <form> elements and submit handlers. See Forms & Binding.

PropertyDescription
$form.dataSnapshot of all named form field values.
$form.reset()Resets inputs and scope state to initial values.
$form.isDirtytrue if any input was modified.
$form.isValidtrue if HTML5 validation passes.

$nextTick — async DOM flush

Available inside script functions. Returns a Promise that resolves after Lyap finishes flushing pending reactive updates to the DOM.

<script type="lyap">
    state({ count: 0 });

    async function bump() {
        count++;
        await $nextTick();
        // DOM is now guaranteed to reflect the new count
        console.log(document.querySelector('p').textContent);
    }
</script>
<p ly-text="count"></p>
<button ly-on:click="bump">Bump</button>

Context matters. $event exists only in event handlers, $form only inside forms, and $refs/$scope/$el throughout a scope. Lyap injects exactly what's relevant.
