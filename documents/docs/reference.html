Directive Reference

Every directive at a glance. Directives are HTML attributes Lyap recognizes when it walks the DOM.

Directives

DirectivePurposeExample
ly-cloak Hides a container until Lyap initializes (prevents FOUC). <div ly-cloak>
ly-text Sets text content safely — anti-XSS. <span ly-text="user.name">
ly-on:* Listens to DOM events. Modifiers: .outside, .self, .prevent, .stop, .once, .window, .enter, .escape. Prefix : for inline expressions. ly-on:click.outside=":open = false"
ly-bind Two-way input binding with IME protection. Modifiers: .trim, .number, .debounce(ms). <input ly-bind.trim="username">
ly-class Dynamic class toggling with :condition class1 class2 tokens. ly-class=":isActive active"
ly-attr:* Binds any element attribute dynamically. <button ly-attr:disabled="!isValid">
ly-show Toggles CSS visibility (display: none). <p ly-show="isOpen">
ly-if / ly-else-if / ly-else Conditional DOM insertion / omission via <template>. <template ly-if="isLoggedIn">
ly-for Iterates arrays, numbers or objects with index and key tracking. <template ly-for="item in items">
ly-key Stable identity for items rendered by ly-for. <div ly-key="item.id">
ly-ref Registers a named element reference accessible via $refs. <input ly-ref="searchInput">

Lyap script API

Inside a <script type="lyap"> block:

APIPurpose
state({...})Declares reactive state properties.
derived({...})Declares read-only computed values, lazily memoized and auto-updating.
init(fn)Runs during scope creation, before the DOM is live.
mount(fn)Runs after the element and scope are attached to the DOM.
cleanup(fn)Registers teardown for resources created inside mount().
destroy(fn)Runs when the container scope is destroyed.
function name() {...}Declares a callable action with direct access to state.

Global API

The library exposes itself as Lyap on window:

Lyap.version            // '2.0.0-proto'
Lyap.walk(element)      // process a subtree manually
Lyap.evaluate(expr, ctx) // evaluate a lyap expression
Lyap.signal(value)      // low-level reactive signal
Lyap.effect(fn)         // run a reactive effect
Lyap.store(obj)         // create a reactive store
Lyap.computed(fn)       // create a computed value

Notes

  • Structural over convenience — behavior follows HTML structure and scope boundaries.
  • CSP compliant — no eval(), no new Function() anywhere in the runtime.
  • Guard rails — duplicate state keys across scripts in one container trigger a console warning.
  • Scope inheritance — children read parent state through prototypal delegation.
