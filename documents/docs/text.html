Text, Show & Cloak

Three small directives cover most everyday needs: ly-text binds content safely, ly-show toggles visibility, and ly-cloak prevents that ugly flash on load.

ly-text — safe text binding

ly-text binds an element's text content to an expression. It sets textContent, which automatically escapes HTML — text can never be injected as markup.

<span ly-text="name"></span>
<p ly-text="'Hello, ' + user.name + '!'"></p>
<p ly-text="items.length + ' items'"></p>

XSS-safe by default. ly-text uses textContent internally, so user-provided strings render as plain text — never as HTML.

ly-show — toggle visibility

ly-show toggles an element's display style. The element stays in the DOM — only its visibility changes.

<p ly-show="open">This paragraph toggles visibility.</p>
<button ly-on:click=":open = !open">Toggle</button>

For content that should be added and removed from the DOM entirely — not just hidden — use ly-if instead. See Conditionals & Loops.

ly-cloak — prevent FOUC

When a page loads, Lyap has not yet processed the markup. A bound element could briefly show raw, unstyled content. ly-cloak hides the container until Lyap initializes, then the attribute is removed.

<style>
    [ly-cloak] { display: none !important; }
</style>

<div ly-cloak>
    <script type="lyap">
        state({ count: 0 });
    </script>
    <h1 ly-text="count"></h1>
</div>

Tip: the rule [ly-cloak] { display: none !important; } should live in your page's CSS. Without it, ly-cloak has nothing to apply until Lyap runs.
