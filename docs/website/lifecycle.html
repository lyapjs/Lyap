Lifecycle & Scopes

Every Lyap container element owns an isolated scope. Lifecycle hooks allow precise setup, mount, cleanup, and teardown management.

Scoped scripts

A <script> block calling Lyap.scope('name') binds to its nearest parent container element.

<div>
    <script>
        const app = Lyap.scope('app');
        app.state({ count: 0 });

        app.init(() => {
            console.log('Scope initialized');
        });

        app.onMount(() => {
            console.log('Mounted container to DOM');
        });

        app.onDestroy(() => {
            console.log('Scope destroyed');
        });
    </script>
    <p ly-text="app.count"></p>
</div>

init — scope preparation

scope.init(() => {...}) runs during scope registration before directives are bound.

onMount — attached to DOM

scope.onMount(() => {...}) runs immediately after the DOM container is walked and mounted. Wire up timers, event listeners, or observers here.

cleanup & onDestroy

Register cleanup callbacks via scope.cleanup(() => {...}) or scope.onDestroy(() => {...}) to release resources, clear intervals, or disconnect observers when the element unmounts.

Scope hierarchy

Child scopes resolve ancestor state seamlessly by name:

<div id="parent">
    <script>
        const parentScope = Lyap.scope('parentScope');
        parentScope.state({ organization: 'Lyap Labs' });
    </script>

    <div id="child">
        <script>
            const childScope = Lyap.scope('childScope');
            childScope.state({ service: 'Auth Gateway' });
        </script>

        <p>Service: <span ly-text="childScope.service"></span></p>
        <p>Org: <span ly-text="parentScope.organization"></span></p>
    </div>
</div>
