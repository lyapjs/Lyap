How Lyap.js Works in 3 Simple Steps

Lyap adds reactivity directly to your standard HTML elements.

1️⃣ Include Library

Add <script src="lyap.min.js"></script> in your <head> tag.

2️⃣ Write HTML Directives

Use HTML attributes like ly-text, ly-on:click, ly-model, and ly-for.

3️⃣ Define Scope State

Write a <script> inside your element with Lyap.scope('name').state({...}).

Directives Quick Reference Table

Every directive starts with ly- and performs a specific reactive job:

Directive What it does Example
ly-text Displays text reactively (safe from HTML injection) <span ly-text="app.username"></span>
ly-show Toggles element visibility using the hidden attribute <div ly-show="app.isLoggedIn">Welcome!</div>
ly-bind:ATTR Binds HTML attributes or properties (e.g. class, disabled) <button ly-bind:disabled="app.isSaving"></button>
ly-model Two-way syncs input, checkbox, radio, or select with state <input type="text" ly-model.trim="app.query">
ly-on:EVENT Listens to DOM events (click, submit, etc.) and calls actions <button ly-on:click="app.save()">Save</button>
ly-if / ly-else Conditionally mounts or unmounts elements from the DOM <p ly-if="app.count > 0">Positive</p>
ly-for / ly-key Loops over arrays and objects with in-place keyed rendering <li ly-for="item in app.items" ly-key="item.id"></li>
ly-ref:NAME Stores a direct DOM element reference on this.$refs <input ly-ref:emailInput>

📖 Beginner Code Walkthrough

How this counter is created with standard HTML:

HTML & Inline Script
<!-- 1. Define State and Actions -->
<script>
  const counterApp = Lyap.scope('counterApp');
  
  counterApp.state({ count: 0, step: 1 });
  
  counterApp.derived({
    doubleCount: () => counterApp.count * 2
  });
  
  counterApp.actions({
    increment() { this.count += this.step; },
    reset() { this.count = 0; }
  });
</script>

<!-- 2. Display with ly-text -->
<h1 ly-text="counterApp.count"></h1>
<p>Double: <span ly-text="counterApp.doubleCount"></span></p>

<!-- 3. Bind Input with ly-model.number -->
<input type="number" ly-model.number="counterApp.step">

<!-- 4. Trigger Actions with ly-on:click -->
<button ly-on:click="counterApp.increment()">+</button>
<button ly-on:click="counterApp.reset()">Reset</button>

How array looping works without virtual DOM diffing:

Loop Template Syntax
<!-- 1. Form Submission with .prevent modifier -->

<div ly-if="todoApp.totalCount === 0">No tasks</div>

<!-- 3. Keyed Loop with ly-for and ly-key -->
<ul ly-else>
  <li 
    ly-for="todo in todoApp.todos" 
    ly-key="todo.id"
    ly-bind:class="todo.done ? 'completed' : ''"
  >
    <input type="checkbox" ly-model="todo.done">
    <span ly-text="todo.text"></span>
